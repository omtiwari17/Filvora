How to Pull & Update Running Code Deployment Runbook

When you push new bug fixes or features from your PC to GitHub, run these commands in your phone's Termux:

⚡ 1-Click All-in-One Instant Update
update

Or run the direct pipeline: cd ~/Filvora && git pull && python manage.py migrate && pkill -f "python manage.py runserver" && nohup python manage.py runserver 0.0.0.0:8000 > ~/filvora.log 2>&1 &

1 Pull Latest Code from GitHub
Downloads newly pushed commits into your phone's Filvora repository.
cd ~/Filvora && git pull
2 Run Database Migrations
Applies any new database tables or column schema changes safely.
python manage.py migrate
3 Stop the Old Server Process
Terminates the previous running instance so Python loads your new code.
pkill -f "python manage.py runserver"
4 Start Updated Server in Background
Relaunches the server with nohup so it continues running after SSH disconnects.
nohup python manage.py runserver 0.0.0.0:8000 > ~/filvora.log 2>&1 &
5 Verify Startup in Logs
Checks that Django started cleanly without errors.
tail -n 20 ~/filvora.log
